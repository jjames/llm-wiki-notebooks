# Exploratory Notebooks

These files are early working notes, not curriculum notebooks:

- `calculus_exploration.ipynb` explores finite-difference derivatives.
- `scalar_autograd_exploration.ipynb` contains partial computational-graph notes.

They are preserved as source material and provenance for [`17_autodiff_from_scratch.ipynb`](../17_autodiff_from_scratch.ipynb). They may rely on exploratory kernel state and are deliberately excluded from clean-kernel curriculum execution. Do not follow their filenames as part of the numbered learning path.
